Como coletar os dados

O pg_stat_activity é uma foto instantânea. Para ver a carga ao longo do dia, colete fotos periódicas (por exemplo, a cada 15 s), como o ASH do Oracle faz. Cada sessão ativa numa amostra vale um intervalo de tempo de banco; somando, temos as sessões ativas médias e o custo de cada SQL.

1. Coleta com psql (qualquer máquina com acesso ao banco)

#!/usr/bin/env bash
# Uso: INTERVALO=15 ./coleta_pg_activity.sh "host=db1 dbname=postgres user=monitor" saida.csv
CONN="${1:?informe a string de conexao}"; OUT="${2:-pg_activity_$(date +%Y%m%d).csv}"; INTERVALO="${INTERVALO:-15}"
SQL="SELECT now() AS sample_time, pid, leader_pid, datname, usename, application_name, client_addr,
            backend_type, backend_start, xact_start, query_start, state_change, state,
            wait_event_type, wait_event, query_id, query
       FROM pg_stat_activity
      WHERE pid = pg_backend_pid()  -- marca o instante mesmo sem atividade
         OR (query <> '' AND (state = 'active' OR state_change >= now() - interval '${INTERVALO} seconds'))"
HDR=HEADER; [ -s "$OUT" ] && HDR=""
while true; do
  psql "$CONN" -X -q -v ON_ERROR_STOP=1 -c "COPY ($SQL) TO STDOUT WITH (FORMAT csv $( [ -n "$HDR" ] && echo ', HEADER'))" >> "$OUT" && HDR=""
  sleep "$INTERVALO"
done

PostgreSQL 13 ou anterior: remova query_id (14+) e leader_pid (13+). A versão completa, que detecta isso sozinha, está em tools/pg-top-activity/coleta_pg_activity.sh.

2. Planos de execução (auto_explain)

O pg_stat_activity não guarda planos. Ligue o auto_explain para registrar no log o plano de toda SQL lenta, e depois abra o log aqui em Abrir planos…. Os planos são associados às SQLs pelo query_id ou pelo texto normalizado.

# postgresql.conf (ou ALTER SYSTEM + pg_reload_conf())
session_preload_libraries = 'auto_explain'
auto_explain.log_min_duration = '2s'     # só SQLs acima disso
auto_explain.log_analyze = on            # tempos reais por nó
auto_explain.log_buffers = on
auto_explain.log_timing = off            # reduz o overhead do analyze
auto_explain.log_verbose = on            # inclui o Query Identifier (PG 14+)
auto_explain.log_format = json

Sem auto_explain, abra uma SQL no painel, gere o comando EXPLAIN na aba Plano, rode no banco e cole a saída ali mesmo.

Aurora / RDS

Use tools/pg-top-activity/aurora/ash_aurora.sh: coleta contínua numa EC2, baixa os logs do Aurora pela AWS (planos do auto_explain e SQLs lentas com binds) e envia os últimos 7 dias por email. Os dois anexos abrem aqui: o .csv.gz em Abrir amostras… e o .log.gz em Abrir planos…. Com os binds, a aba Plano gera o EXPLAIN ANALYZE com os valores reais.

Formatos aceitos

CSV (de COPY/\copy), TSV, JSON (array, json_agg ou uma linha por objeto), saída do psql em tabela ou em \x, e arquivos .gz. Só a coluna query é obrigatória; sem sample_time, o arquivo é tratado como uma foto única e o custo vira o tempo decorrido de cada execução. Tudo roda no seu navegador: nenhum dado sai da máquina.
